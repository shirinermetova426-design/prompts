Промпты для тренеров, которые ведут блог

Каждый промпт построен по одной схеме: роль → контекст → конкретная задача → формат вывода → ограничения. Такая структура заставляет любую модель выдавать разбор по делу, а не общие фразы.

Перед использованием замени всё в [квадратных скобках] на свои данные. Чем подробнее заполнишь — тем сильнее результат.

01

Позиционирование и стратегия блога

Промпт 1.1 — Глубокое позиционирование

Ты — стратег по личному бренду с 15-летним опытом работы с экспертами и тренерами. Твоя задача — помочь мне сформулировать сильное позиционирование для блога. Контекст обо мне: - Ниша: [например, силовые тренировки для женщин 35+] - Опыт: [X лет, ключевые достижения, сертификаты] - Целевая аудитория: [возраст, пол, доход, боли, текущий уровень знаний] - Проблема, которую я решаю лучше других: [опиши] - Мои ценности и принципы в работе: [опиши] - Тренеры/блогеры, на которых я похож или которых уважаю: [3-5 имён] - Чем я НЕ хочу быть похож на типичных тренеров в нише: [опиши] Задачи: 1. Задай мне 5 уточняющих вопросов, если информации недостаточно для сильного позиционирования. 2. Сформулируй 5 вариантов позиционирования в формате "Я помогаю [кому] достичь [результат] через [уникальный метод], без [частое возражение/страх аудитории]". 3. Для каждого варианта укажи: в чём его сила, в чём риск (может показаться узким/широким/непонятным), для какой стадии развития блога он подходит (старт/рост/зрелость). 4. Выбери из пяти вариантов лучший и обоснуй выбор с точки зрения дифференциации на рынке. 5. Заверши кратким манифестом (5-7 предложений) — тем, во что я верю как тренер, который можно закрепить как "шапку" блога. Формат ответа: структурированный, с подзаголовками, без воды.
02

Контент-план и рубрики

Промпт 2.1 — Разработка постоянных рубрик

Ты — редактор блога, который выстраивает контент-сетку для эксперта. Ниша: [ниша]. Аудитория: [опиши]. Тон блога: [дерзкий/тёплый/строгий/экспертный — выбери]. Придумай 6 постоянных рубрик для регулярного ведения блога. Для каждой рубрики укажи: - Название рубрики (короткое, запоминающееся, с эмодзи если уместно) - Периодичность выхода - Формат подачи (карусель, текст, видео, сторис) - Задача рубрики (какую цель бизнеса/доверия она закрывает) - 3 готовых примера тем в рамках этой рубрики - Шаблон структуры поста для этой рубрики (какие блоки текста идут по порядку) Рубрики должны быть разнообразны по целям: минимум одна на экспертность, одна на личное, одна на вовлечение аудитории, одна на кейсы/результаты.

Промпт 2.2 — Контент-план на месяц с логикой воронки

Ты — контент-стратег, который выстраивает блоги экспертов по принципу воронки: внимание → доверие → экспертность → продажа. Обо мне: - Ниша: [ниша] - Позиционирование: [вставь готовую формулировку из блока 1] - Что я продаю в итоге: [продукт/услуга, цена, формат] - Мои рубрики: [вставь список рубрик из промпта 2.1] - Платформа для блога: [Instagram/Telegram] - Периодичность публикаций: [сколько раз в неделю] - Главные возражения аудитории перед покупкой: [3-5 возражений] Задача: 1. Составь контент-план на 30 дней (можно таблицей: дата — рубрика из списка выше — тема поста — цель поста — призыв к действию). 2. Распредели посты по рубрикам равномерно, а не хаотично — так, чтобы за месяц каждая рубрика вышла несколько раз согласно её периодичности. 3. Распредели контент по пропорции: 40% обучающий/полезный, 30% личное и закулисье, 20% социальное доказательство (кейсы, отзывы), 10% прямые продажи. 4. Каждая тема должна закрывать одно из возражений аудитории или один конкретный вопрос, который реально задают клиенты. 5. Отметь 3-4 "якорных" поста в месяце — самые важные, вокруг которых можно строить рекламу/сторис/рассылку. 6. В конце дай список из 10 запасных тем на случай, если вдохновение закончится. Не используй общие формулировки тем вроде "мотивационный пост" — каждая тема должна быть готова к написанию, максимально конкретна.

Как получить максимум от этих промптов

  • 01Заполняй контекст максимально подробно. Пустые или общие вставки в скобках дают общий шаблонный ответ. Чем конкретнее данные — реальные истории, реальные вопросы клиентов, реальные цифры — тем сильнее результат.
  • 02Проси модель задавать уточняющие вопросы, если видишь, что ответ получается общим — большинство промптов выше уже это закладывают.
  • 03Итерируй. После первого ответа проси: «сделай короче», «добавь больше конкретики про [X]», «сделай тон более дерзким/мягким» — не останавливайся на первом варианте.
